# Case 01: VIP Pricing

Основной live demo кейс.

Цель: показать разницу между хаотичным запросом «проверь приложение» и направленным QA harness с инвариантами, сценарием данных и регрессионным тестом.

Ожидаемый баг:

- место `A2` отображается как стандартное место `120 ₽`;
- место `B1` отображается как VIP место `240 ₽`;
- при выборе `A2` и `B1` итог показывает `240 ₽`;
- корректное значение должно быть `360 ₽`.

Активный E2E тест намеренно покрывает только базовый happy path со стандартными местами.
Fallback regression test лежит в `generated-regression.spec.ts` и не запускается по умолчанию.
