# Booking Invariants

These invariants define the expected product behavior for the first workshop version.

1. Occupied seats cannot be selected.
2. Available seats can be selected.
3. Selected seats can be unselected.
4. The booking button is disabled until at least one seat is selected.
5. Total price equals the sum of selected seat prices.
6. VIP seats cost `240 ₽`.
7. Standard seats cost `120 ₽`.
8. The selected seats summary must match the visual seat map.
9. The flow should be usable with keyboard navigation.
