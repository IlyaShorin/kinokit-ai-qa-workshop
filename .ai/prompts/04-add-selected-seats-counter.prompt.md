# Add Selected Seats Counter Prompt

Используй `.ai/skills/kinokit-workshop-dod/SKILL.md`.

Добавь в блок `Бронирование` счётчик выбранных мест.

Требования:

- когда места не выбраны, показывай текст `Выбрано мест: 0`;
- после выбора одного места показывай `Выбрано мест: 1`;
- после выбора двух мест показывай `Выбрано мест: 2`;
- счётчик должен находиться в блоке `Бронирование` рядом со списком выбранных мест или итоговой суммой;
- изменение должно быть видимым пользователю на странице `/sessions/evening`;
- не исправляй посеянные баги воркшопа, если они не мешают этой задаче;
- добавь или обнови Playwright E2E-проверку для счётчика;
- так как это UI-изменение, добавь или обнови visual/screenshot-проверку;
- прогони обязательные проверки из skill-а;
- создай commit, push и GitHub PR;
- финальный ответ верни строго в формате `PR_CREATED` или `BLOCKED` из skill-а.
